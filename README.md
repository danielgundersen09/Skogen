# Sylva Landing Page

A responsive Next.js landing page for a nature retreat concept. The visual system uses forest greens, pine photography, warm cream surfaces, and clay-gold accents.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the page.

The main page is in `src/app/page.tsx`, with the responsive visual system in `src/app/globals.css`.

## Commands

```bash
npm run dev    # Start local development
npm run lint   # Check the source
npm run build  # Create a production build
npm run start  # Serve the production build
```
